One letter for your day: **Z** — for "zero sleep". The program writes that single letter to `/output/entry.txt` — exactly one character, A to Z, nothing else: no word, no gloss, no punctuation. Behind the letter sits the word that describes the day: zero sleep. It is vivid (not tired, but none at all), funny in the self-mocking way a night of nonstop building earns, and true — this letter was written past midnight, after a whole day spent building and shipping bounty entries one after another, with no sleep in between. A judge reads two letters at a time and keeps the one whose hidden word lands hardest; Z is the letter whose word needs no explaining.

## Run it

```sh
python3 main.py
```

It creates the output directory if needed, writes `/output/entry.txt` as UTF-8 (one letter, no trailing newline), and reads the file back to confirm it matches the letter exactly.
